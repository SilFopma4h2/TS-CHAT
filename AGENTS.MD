# DuoChat development rules

This project is developed by two people using Claude Code.

SIL owns:
- frontend/
- infra/
- deployment configuration

TWAN owns:
- backend/
- database/

Shared:
- docs/
- README.md

Do not modify another developer's area unless explicitly required.

Never rewrite existing work just to use a different implementation.

API contracts must be documented in docs/API.md.

Run tests before committing.
Use small focused commits.
